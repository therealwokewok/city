# State packs

A pack is one small JSON file named for the state, like `MO.json`. It gives a new city sensible starting values and a list of things to confirm with the city's attorney.

A pack never sets rates and never overrides anything later. Every value can be changed under Administration, City settings.

To add your state, copy `MO.json`, rename it, and change the values. Only keys the settings screen knows about are allowed. Pull requests are welcome, but please do not claim a value is legally required unless you can cite it.
