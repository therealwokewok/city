# city

Free, open-source software for small cities.

| Folder | What it is |
|---|---|
| [`utilities/`](utilities/) | Utility billing and management: meter readings, bills, online payments, autopay, service requests, shutoffs, and printing. Apache 2.0. Start with [`utilities/README.md`](utilities/README.md). |

Each folder is self-contained, with its own tests, install notes and releases. Releases of `utilities` are tagged `utilities-v1.2.3`.
